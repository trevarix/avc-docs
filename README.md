# AVC Documentation Site

The public documentation site for Agentic Version Control (AVC), built with [Astro Starlight](https://starlight.astro.build).
Lives at **https://avc.trevarix.com**.

## Local development

```bash
npm install                # one-time setup
npm run dev                # http://localhost:4321/
npm run build              # production build → dist/
npm run preview            # serve the production build locally
```

## Project structure

```
avc-docs/
├── astro.config.mjs           # Starlight config (sidebar, logo, edit links)
├── src/
│   ├── assets/
│   │   └── logo.svg           # Brand mark used in the top bar
│   ├── styles/
│   │   └── custom.css         # AVC accent colors + fonts
│   └── content/docs/          # All documentation pages live here
│       ├── index.mdx          # Landing page (splash hero)
│       ├── why.md
│       ├── install.md
│       ├── quick-start.md
│       ├── concepts/          # Snapshots, branches, merges, storage
│       ├── cli/               # Per-command reference (autogenerated sidebar)
│       ├── extension/         # VSCode extension guide
│       ├── web-ui/            # Standalone web UI + REST API
│       └── agents/            # MCP server + per-framework integration
├── public/                    # Static assets (favicon, etc.)
└── package.json
```

## How content is organized

- **Manual sidebar entries** (in `astro.config.mjs`) for Introduction and Concepts
- **Autogenerated sidebars** for CLI, Extension, Web UI, Agent Integration — just drop a new `.md` file in the right folder and it shows up

Each page accepts a `sidebar: { order: N }` frontmatter field to control its position within an autogenerated group.

## Deployment

Deployed on [Vercel](https://vercel.com) at the custom domain `avc.trevarix.com`
(served at the root, no `base` path). Pushing to `main` triggers a production
deploy automatically.

## Editing pages

Every page in the deployed site has an **Edit this page** link in the footer
that opens the source `.md` file in the GitHub editor.
